## 全端通用

### 功能边界与可理解性

- [ ] 地图底部“记录”菜单：打开和关闭动画期间，原生快捷打卡入口不浮在菜单上；四个选项与取消均可点，小屏及大字体下菜单可滚动
- [ ] 当前位置打卡：附近有已保存地点与附近无地点两种弹层，快捷打卡入口都不盖住按钮；长地名、大字体、短屏时主操作、次操作和取消均能看到并点到
- [ ] 地图足迹详情与筛选：打开和退场期间底部按钮、地图控制按钮不抢触点；弹层内容过长可滚动，关闭后快捷入口恢复

- [ ] 会员等级：免费、7 天体验、Plus、Pro、临期和已过期状态在“我的”、会员页与成长页名称一致；当前等级和下一等级新增权益一眼可辨
- [ ] 权益回顾：免费用户可看本月；Plus 可打开历史月份；Pro 可打开年度回顾；只有相邻两年都有记录时才显示跨年对比
- [ ] Plus 升 Pro：购买前明确显示 ¥99 全价、Pro 从生效时起算 372 天，原 Plus 到期时间不缩短、不折价、不暂停
- [ ] 想去地图：北京、南通等只有省市而无 POI 坐标的卡片，逐张切换后地图聚焦对应城市，并明确标为“城市范围”；不能把另一条足迹或省份中心当作该城市。
- [ ] 想去地图：只有省份、城市不明的卡片显示“待补充位置”，点按后提供补位置入口；它本身不进入选中态，原先选中的卡片与地图目标保持一致。
- [ ] 点亮地图：已到访城市分别有可见地图标记与城市名；上海和南通等邻近城市进入时不叠在一起，点城市标记可打开所属省区卡片；未到访和仅想去的城市没有标记
- [ ] 快捷打卡：地图底部按钮的白色定位图标在 iOS、Android 真机都能看见，点击后可继续完成打卡；单纯获取当前位置不会生成足迹标记
- [ ] 多机型截图：每台设备实际生成足迹详情截图；无足迹数据时报告明确记为跳过，不能算作通过。
- [ ] Lumi 颜色：直接点击颜色卡片任意位置即可切换；有切换中、成功和失败反馈；自动调整可一键恢复；无需再点击卡片外的“选择”按钮
- [ ] 回忆票根：不看说明也能区分“记录再次到访”（创建新记录）与“珍藏这张票根”（仅为当前记录加标记）；分别检查单次与多次到访
- [ ] 回忆票根：页面和右上角菜单都没有转发入口；项目页面配置里没有票根分享页；新增功能先对照“现阶段不做直接分享”的产品边界

### 全局交互性能

- [ ] 开启 `sgj:perf-debug` 后，分别在 iPhone 与 Android 使用 0 / 100 / 1000 条固定数据测试；每项重复 20 次并保存 p50、p95 和录屏
- [ ] 连续执行「地图 → 时光 → 我的 → 地图」50 轮，页面可操作、导航选中正确；足迹模式回到当前位置，想去与点亮模式保留各自目标视野，隐藏页面没有持续更新日志
- [ ] 地图模式、筛选、标记详情、日历选日和翻月、时间线加载更多、详情票根与标记重要均有即时点击反馈
- [ ] 新增和编辑足迹时，照片最多 2 张并发上传；部分失败保留成功项，只重试失败项，上传未完成不能保存
- [ ] 保存完成不再出现第二段全量加载；网络失败、定位拒绝、快速重复点击不会产生重复记录或旧结果覆盖
- [ ] 1000 条数据下，主导航普通点击不出现成长距离扫描长任务；成长页的「远方」状态随后异步补齐

- [ ] 眉头文案：攻略页 WISHLIST & PLANS、隐私页 DATA & PRIVACY 的「&」显示正常（本次修复点）
- [ ] 云开发环境：登录、足迹保存、胶囊提醒在真实环境可用（模拟器期间走的是本地回退）
