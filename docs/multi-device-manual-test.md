## iOS（iPhone）
- [ ] 会员页购买按钮：iOS 走虚拟支付分支（代码里 `platform === 'ios'` 要求微信 ≥8.0.68），确认低版本微信的提示弹窗文案正确
- [ ] 底部安全区：带 Home Indicator 机型上，悬浮 tabBar、底部主按钮与指示条不重叠
- [ ] 输入框聚焦：昵称/表单输入聚焦时页面不被键盘顶飞、字体不触发自动放大（font-size ≥16px）
- [ ] AI 助手文本框：键盘弹起时「生成可编辑草稿」按钮仍可见可点
- [ ] 刘海屏状态栏：地图页 statusBarHeight 适配（导航栏不与系统状态栏重叠）

## Android（华为/小米/Pixel 任一）
- [ ] rpx 取整差异：设置页开关、标签、日历格子无 1px 级错位/毛边
- [ ] 无安全区机型：悬浮 tabBar 距底边间距正常（不贴边、不过分离）
- [ ] 地图 SDK：地图瓦片加载、定位蓝点、选点页（chooseLocation）正常返回
- [ ] 返回手势/物理返回键：从足迹详情、表单、胶囊详情返回不丢数据
- [ ] 虚拟支付：Android 走非 iOS 分支的购买路径正常

## iPad

- [ ] 按钮单行：保存资料、封存一段回忆、生成攻略、去地图添加（本次修复点，重点回归）

- [ ] 分屏/悬浮窗（如开启 resizable）：布局不塌；未开启则确认固定竖屏窗口居中显示
